Team Software Project, Guitar Hero Clone

This was a group project for my Team Software Project module last year. Our group built a clone of the game guitar hero. Here is the demo recorded my teammate of our semi-complete version.

We built it using several tools and platforms including Python, a rasberry pi and pygame for the software team. The design team used Figma, Noteful and PicsArt. I was apart of both teams, I designed all the characters implemented in the game and several screen for the game.

I also worked on building a controller for the game which i built using Python and the rasberry pi. I built buttons and researched button logic and debouncing.
